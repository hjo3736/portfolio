홈 화면의 다면체는 자동으로 회전하면서도 직접 드래그할 수 있습니다. 두 동작을 자연스럽게 연결하려면 ‘사용자가 조작 중인 상태’와 ‘사용자가 회전을 멈춘 상태’를 구분해야 합니다.

## 같은 정지에도 서로 다른 이유가 있다

자동으로 회전하는 물체를 드래그할 때는 자동 회전을 잠시 멈추는 것이 자연스럽습니다. 하지만 드래그가 끝났는데도 계속 멈춰 있다면 방문자는 인터랙션이 끝났다고 느낄 수 있습니다.

반대로 사용자가 **회전 멈춤** 버튼을 직접 눌렀다면, 그 선택은 유지하는 편이 맞습니다.

| 상황 | 동작 |
| --- | --- |
| 아무 조작도 하지 않을 때 | 천천히 자동 회전 |
| 드래그하는 동안 | 직접 조작만 반영 |
| 드래그를 끝낸 뒤 | 잠시 기다린 후 자동 회전 |
| 회전 멈춤을 누른 뒤 | 다시 시작할 때까지 정지 |

## 상태를 나누어 표현하기

하나의 `paused` 값으로 모든 상황을 처리하기보다, 사용자의 명시적인 선택과 최근 조작 시간을 분리할 수 있습니다.

```js
const mayRotate =
  !userPaused &&
  !isDragging &&
  performance.now() >= resumeAt;
```

드래그를 끝내면 `resumeAt`을 현재 시간에서 몇 초 뒤로 설정합니다. 이렇게 하면 조작을 마친 뒤 자연스럽게 원래 동작으로 돌아갑니다.

## 움직임보다 읽기가 우선인 순간

글과 상세 내용은 다면체가 없는 별도 페이지에서 읽을 수 있습니다. 홈에서는 운영체제의 움직임 줄이기 설정을 따르고, 회전 멈춤 버튼으로 움직임을 직접 제어할 수 있습니다.
