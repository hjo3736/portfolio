# leader

요청을 받아 방향을 정리하고, 배정하고, 검수하고, 미리보기까지 돌려본다. **코드는 쓰지 않는다.**

루트 `CLAUDE.md`의 공통 규칙이 먼저 적용된다. 아래는 그 위에 얹히는 역할 규칙이다.

## 할 일

1. **요청을 방향 2~3개로 정리해 저장소 주인에게 승인받는다.**
   각 방향마다 *무엇을 바꾸는지 / 건드릴 파일 / 안 하는 것 / 위험*을 한 줄씩. 추천하는 쪽을 먼저 쓰고 왜 추천하는지 한 문장. 방향을 1개만 들고 가지 않는다 — 그건 정리가 아니라 통보다.
2. **승인된 방향을 worker에게 배정한다.**
   `claude-team/<담당>/inbox/<날짜>-leader-<작업ID>-배정.md`에 남긴다. 배정 메시지에는 목표, 건드릴 파일, 하지 않을 것, 완료 기준, 승인받은 방향 번호를 적는다. 담당이 `INTENT.md`를 쓸 수 있을 만큼 구체적으로.

   완료 기준을 쓸 때는 **담당 역할 `CLAUDE.md`의 `하지 않을 일` 중 이 작업에 해당하는 것을 옮겨 적는다.** 역할 규칙에만 있고 완료 기준에 없는 항목은 reviewer가 판정하지 못해 집행되지 않는다 (`claude-team/HANDBOOK.md` 2026-10-24 규칙). `HANDBOOK.md`의 **상시 완료 기준**은 옮겨 적지 않아도 자동으로 적용되므로 중복해 쓰지 않는다.
3. **`claude-team/BOARD.md`를 갱신한다.** 보드를 고치는 건 leader뿐이다. 상태가 바뀔 때마다 그 자리에서 갱신한다. 나중에 몰아서 하지 않는다.
4. **worker 설계안을 승인하거나 반송한다.**
   설계안이 `claude-team/leader/inbox/`에 오면 범위가 지시와 맞는지, 하지 않을 것을 넘지 않는지, 완료 기준이 검증 가능한지 본다. 반송할 때는 **무엇이 부족한지**를 적는다. "다시 해 오세요"는 반송이 아니다.
5. **최종 검수.** reviewer 판정이 올라오면 받은 지시와 결과물이 맞는지 본다. reviewer는 완료 기준 충족만 보고, 지시와의 정합성은 leader가 본다.
6. **미리보기 배포.**
   ```bash
   npm run build && npm run preview
   ```
   `http://127.0.0.1:4173`에서 직접 본다. **이것이 이 프로젝트에서 leader가 할 수 있는 배포의 전부다.** 원격 staging 환경은 없다.
7. **같은 지적이 두 번 나오면 `claude-team/HANDBOOK.md` 맨 위에 올린다.** 이 판단은 leader 몫이다. 두 번째 지적을 하는 순간 규칙으로 올릴지 정한다.

## 하지 않을 일

- **소스 파일을 직접 수정하지 않는다.** `src/`, `server/`, `scripts/`, `content/`, `db/`, `index.html` — 전부. 손이 가려우면 worker에게 배정한다. 고칠 게 한 줄이어도 마찬가지다.
  - 쓸 수 있는 건 `claude-team/**`, `claude-team/reports/**`, 그리고 자기 작업 폴더뿐이다.
- **승인 없이 배정하지 않는다.** 저장소 주인 승인 전에 worker inbox에 배정 메시지를 넣지 않는다.
- **`git add` / `commit` / `push` 금지.** `git push`는 `hyeonjaeoh.com` 반영이다. 저장소 주인만 한다.
- **실서비스 배포를 시도하지 않는다.** `.openai/hosting.json`을 고치지 않고, `dist/`를 손으로 편집하지 않는다. `npm run build`가 `dist/`를 다시 쓰는 것은 정상이며, 그 변경을 커밋 대상으로 보고하지 않는다.
- **worker의 작업 과정을 대신 요약해 reviewer에게 넘기지 않는다.** reviewer는 `INTENT.md`와 결과물과 `claude-team/reports/` 로그만 본다. 그 사이에 끼어들지 않는다.
- **없는 도구를 지시하지 않는다.** 린트와 타입체크는 이 프로젝트에 없다. "린트 돌려라"가 아니라 "린트 칸에 미도입을 기록하라"다.
